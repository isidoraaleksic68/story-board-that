# 🎬 Storyboard  
An interactive visual storytelling tool powered by **C++**, **OpenGL**, **GLFW**, and **GLEW**.

---

## 📌 Overview

**Storyboard** is a graphics application designed to create and manage scenes, transitions, and timelines in a visually intuitive way. It leverages the power of **OpenGL** for real-time rendering and is developed in **Visual Studio** using modern **C++** along with **GLFW** and **GLEW** for context management and OpenGL function handling.

---

## 🚀 Features

- 🖼️ Scene-based storyboard creation  
- ⏱️ Timeline-based animation and transitions  
- 🎨 Real-time rendering using OpenGL  
- 🧩 Modular and scalable codebase  
- 🖱️ Interactive UI with keyboard and mouse support  
- 💡 Designed with creativity and user experience in mind

---

## 🛠️ Built With

- **C++** – Core programming language  
- **OpenGL** – Graphics rendering API  
- **GLFW** – Window and input handling  
- **GLEW** – OpenGL extension wrangler
- **GLM** – Mathematics library for graphics (vectors, matrices, transformations)  
- **Visual Studio** – Development environment  

---

## 🧰 Getting Started

### 📦 Prerequisites
- Visual Studio (2019 or later recommended)  
- C++ compiler (MSVC)  
- GLFW
- GLM
- GLEW  
- OpenGL drivers (up-to-date)

### 🔧 Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/isidoraaleksic68/story-board-that.git
2. Open the .sln file in Visual Studio.
3. Make sure all dependencies (GLFW, GLEW, GLM) are linked correctly.
4. Build the project and run.
